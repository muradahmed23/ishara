## iShara 2.0.1 for Windows

**Much smaller download.** Everything you need to use iShara (voice commands and standard voice typing) is still included and works offline right after install.

- New onboarding step: *Do you want high-accuracy typing?* The optional best-accuracy model downloads in the background while you continue the setup (also available later in Settings → Voice).
- Optional model downloads are verified with SHA-256 and resume if interrupted.
- Leaner app: unused libraries removed.
- Your profiles and calibration are kept when you update.

**Install:** download the installer, open it, press Install. Windows 10 (1809+) or 11, 64-bit.

Windows SmartScreen may warn because the installer is not code-signed yet: choose *More info → Run anyway*.
